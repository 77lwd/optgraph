## 🎓 技术细节

### 核心算法：拓扑排序

```python
def _topological_sort(tasks, dep_graph):
    in_degree = {t: len(deps) for t, deps in dep_graph.items()}
    levels = []
    
    while in_degree:
        # 找出入度为0的任务（无依赖）
        current_level = [t for t, d in in_degree.items() if d == 0]
        levels.append(current_level)
        
        # 更新其他任务的入度
        for task in current_level:
            del in_degree[task]
            for other in in_degree.keys():
                if task in dep_graph[other]:
                    in_degree[other] -= 1
    
    return levels
```

**时间复杂度**: O(V + E)
- V = 任务数
- E = 依赖关系数

**本次测试**: 所有任务无依赖，所以都在Level 0并发执行

### 并发执行：asyncio.gather

```python
async def _execute_level(tasks):
    return await asyncio.gather(*[t.execute() for t in tasks])
```

**特点**:
- 非阻塞：协程切换
- 低开销：比线程轻量
- 适合I/O密集型任务（API调用）
